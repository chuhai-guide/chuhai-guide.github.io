# 出海访问指南

**出海访问指南**是一个免费的中文海外网站访问故障排查网站，帮助读者根据实际故障现象，寻找合适的检查方法。

## 网站提供什么

- **交互式故障诊断**：按网站打不开、浏览器报错、登录及验证码异常、访问缓慢等症状逐步查看建议。
- **站内搜索**：搜索常见浏览器错误代码和故障指南。
- **平台访问指南**：针对 ChatGPT、Gemini、Claude、YouTube、TikTok、Netflix、Discord、X、Telegram、Spotify、Zoom、Steam、GitHub、Reddit、Google Drive、Microsoft Teams、Twitch、Canva、Notion、Dropbox 和 Epic Games 的具体访问、登录、播放或语音连接问题。
- **故障指南**：提供 DNS 解析、连接超时、连接重置、证书警告、页面加载、登录循环、Wi-Fi 差异等常见问题的排查步骤。
- **排查记录**：可勾选已完成的步骤，并复制诊断摘要。

诊断建议依据读者提供的现象生成，不代表对设备或目标网站的实时检测。不同故障可能有多个原因，建议一次核对一项条件。

关于访问数据及隐私保护的信息，请参阅网站的[隐私说明](https://chuhai-guide.github.io/privacy.html)。
