平台故障

按平台查找访问问题

同样的“打不开”，在不同平台可能发生于登录、视频、网页资源或实时语音环节。请选择真正遇到的现象。

ChatGPT

ChatGPT 打不开、登录失败或反复验证怎么办？

区分 ChatGPT 无法连接、登录方式不一致、浏览器验证循环和回答加载故障，再决定下一步。

YouTube

YouTube 能打开但视频无法播放、一直缓冲怎么办？

排查 YouTube 视频无法播放、只有播放器黑屏、一直缓冲或提示视频不可用，先区分连接质量与单个视频限制。

TikTok

TikTok 网页版打不开、视频加载失败怎么办？

分别检查 TikTok 网页版和手机 App，区分页面空白、视频不加载、登录异常及账号可用性问题。

Netflix

Netflix 提示 Site Error 或网站无法打开怎么办？

针对 Netflix Site Error 区分浏览器会话、网络连接、设备差异和具体播放错误，避免将账号限制当作 DNS 故障。

Discord

Discord 一直显示 RTC Connecting、语音连接失败怎么办？

区分 Discord 页面打不开与语音 RTC Connecting、ICE Checking、No Route，按语音网络连接特点排查。

Gemini

Gemini 显示错误代码 1060、回答失败怎么办？

区分 Gemini 的 1060 地区可用性提示、回答处理错误、账号权限及浏览器连接异常，按结果排查。

Claude

Claude 登录邮件收不到、登录后又退出怎么办？

针对 Claude 登录链接、Google 登录、邮件未到和浏览器会话异常，区分邮件投递问题与账号访问故障。

X

X（Twitter）网页版打不开、时间线加载失败怎么办？

排查 x.com 页面无法打开、时间线不更新、只在某一浏览器失败等现象，区分浏览器数据与网络连接问题。

Telegram

Telegram 网页版登录不上、验证码收不到怎么办？

区分 Telegram Web 无法打开、登录验证码发送到已登录设备、短信延迟与会话异常，避免误删私密聊天。

Spotify

Spotify 网页播放器打不开或无法播放怎么办？

Spotify 网页播放器空白、歌曲无法播放或只有一个浏览器异常时，先核对浏览器支持、网页权限和播放设备。

Zoom

Zoom 会议加入失败、错误 1020 或 103033 怎么办？

区分 Zoom 网页被防火墙拦截、进入会议时断线、客户端连接故障，并按错误 1020 和 103033 提示排查。

Steam

Steam 下载速度很慢、下载卡住或更新不动怎么办？

Steam 游戏下载卡住、更新排队或速度忽高忽低时，检查下载队列、限速设置、磁盘写入与内容服务器，而不是只看网络测速。

GitHub

GitHub 双重验证无法登录、验证码不通过怎么办？

GitHub 登录卡在双重身份验证时，先确认验证码时间、已登录设备和恢复码，不要盲目重置账号。

Reddit

Reddit 登录失败、密码重置邮件收不到怎么办？

Reddit 登录失败时区分 Google 或 Apple 登录、用户名密码错误、密码重置邮件与双重验证问题。

Google Drive

Google Drive 文件打不开、上传卡住怎么办？

Google Drive 文件无法预览、上传停住或出现临时错误时，分别检查权限、浏览器、网络连接和服务状态。

Microsoft Teams

Microsoft Teams 无法加入会议、一直在大厅等待怎么办？

区分 Teams 会议大厅等待、登录要求、组织策略与网络连接失败，按实际提示处理。

Twitch

Twitch 直播无法播放、提示 Error 2000 怎么办？

Twitch 直播黑屏、缓冲或出现 Error 2000 时，区分网络稳定性、浏览器扩展与单个直播限制。

Canva

Canva 编辑器白屏、卡住或无法保存怎么办？

Canva 打开设计后白屏、编辑器冻结或显示离线重连时，区分浏览器兼容、脚本、连接与保存状态。

Notion

Notion 显示离线、页面无法同步怎么办？

Notion 显示 Offline 或 Connect to the internet、页面同步异常时，区分网络拦截、服务状态与离线页面限制。

Dropbox

Dropbox 上传卡住、网页加载不完整怎么办？

Dropbox 网页上传停滞、文件未同步或文件列表加载异常时，区分浏览器兼容、空间、网络与客户端状态。

Epic Games

Epic Games Launcher 登录失败、一直连接中怎么办？

Epic Games 启动器无法登录、登录循环或连接服务失败时，区分账号会话、启动器缓存和网络连接问题。
