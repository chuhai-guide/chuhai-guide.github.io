Telegram 网页版登录不上、验证码收不到怎么办？

Telegram Web 登录验证码不一定首先发短信：如果还有已登录的 Telegram 设备，先检查应用内是否收到验证码。不要因为网页暂时收不到代码，就急着退出唯一仍登录的设备。

确认手机号和国际区号无误，并在现有设备中查找 Telegram 官方登录消息。清除会话或退出设备之前，先考虑是否有无法在新设备恢复的秘密聊天。

登录码应该去哪里找

Telegram 可能先把登录码发送到其他已登录设备，而不是短信。打开自己仍登录的官方 Telegram 应用，检查列表中经过验证的 Telegram 服务通知会话。输入号码时使用带国家代码的国际格式，并确认号码仍属于自己。

不要把 Telegram 自身登录码与第三方网站发送到“Verification Codes”会话中的验证码混淆；绝不要把登录码交给他人。Telegram 官方说明。

网页打不开与验证码未到，是两件事

如果网页根本无法加载，先记录浏览器错误、比较 Wi-Fi 与移动数据；如果已经进入登录页面，只是收不到代码，继续更改 DNS 往往没有帮助。先检查已登录设备、手机号及平台当前允许的验证方式，避免短时间重复请求。

不要退出唯一仍登录的设备

仍有可用会话时，先核对账号号码、安全设置和设备列表。Telegram 的秘密聊天绑定设备和当前会话，登出会失去该设备上的秘密聊天；不要把“退出再试”当作零风险步骤。

无法访问任何设备时

优先通过 Telegram 官方登录支持渠道反馈，不要购买代收验证码服务，也不要向陌生人提供手机号、验证码或密码。若应用可正常聊天而网页版异常，可再检查浏览器扩展、Cookie 或站点请求。
