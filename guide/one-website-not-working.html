对比排查

为什么一个网站能打开，另一个打不开？

通过域名解析、网站服务状态、网络路径和浏览器配置解释“只有某站打不开”。

先看浏览器显示的是什么

只有一个站点打不开，先保存完整网址和错误提示，不必先重置路由器。不同提示意味着请求停在不同阶段：

  • NXDOMAIN：先核对域名和子域名，检查 DNS 返回值。
  • 证书警告：检查系统时间、网址和证书错误码，不要强行绕过提示登录。
  • 403：网站已经回应，但拒绝了请求；核对账号权限与网站规则。
  • 404：可能是页面地址变化或资源被移除，尝试从网站首页进入。
  • 5xx：网站或上游服务可能有问题，查看官方状态和公告。
  • 连接超时：请求未及时得到回应，继续比较网络和设备。

两次对照就能缩小范围

  1. 在同一设备、同一浏览器，用 Wi-Fi 和移动数据访问同一个完整网址。只有某个网络失败，优先检查该网络的 DNS、代理或过滤设置。
  2. 保持网络不变，改用另一浏览器或隐私窗口。只有一个浏览器失败，优先检查扩展、站点权限及该站点数据。
  3. 若多个网络都失败，查看该网站的官方状态说明；不要因为第三方检测网站说“正常”就排除局部故障。

网页能打开，但登录或视频不行

首页与登录、播放器、验证码可能使用不同子域名或第三方资源。打开开发者工具的 Network，重新加载失败的页面，查看是否某个脚本或媒体请求失败。记录请求域名及 HTTP 状态即可，不要公开含登录令牌的完整请求地址。

如果登录后一直回到登录页，转看登录跳转故障；若出现明确 DNS 错误，转看NXDOMAIN 排查。

暂时不要做的事

其他网站能打开，至少说明设备存在部分联网能力，不代表目标网站一定正常。不要为单站故障直接恢复路由器出厂设置，也不要为解决 403 就反复更换 DNS；权限或服务端问题通常需要网站方处理。
