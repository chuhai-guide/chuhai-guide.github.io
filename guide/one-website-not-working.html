对比排查

为什么一个网站能打开，另一个打不开？

通过域名解析、网站服务状态、网络路径和浏览器配置解释“只有某站打不开”。

先确认：不同错误提示对应的排查方向不同。请保留浏览器显示的完整错误代码，避免同时修改多项设置。

能打开一个网站不代表网络完全正常

不同网站使用不同的域名、DNS、CDN 和服务器；也可能有不同的区域政策与访问控制。

按故障层级比较

  1. 看错误发生的位置

    显示 NXDOMAIN 先查域名解析；证书警告先查 HTTPS；明确 403 则可能是权限或网站防护策略。

  2. 比较不同网络

    同一设备使用 Wi-Fi 和移动数据访问，能帮助判断网络出口影响。

  3. 确认网站服务状态

    查看网站官方状态页、公告或支持渠道，不要把所有故障归为本地网络问题。

  4. 对比浏览器

    若仅一个浏览器失败，检查扩展、站点数据和隐私限制。

如何理解 403 与 5xx

HTTP 403 表示服务器拒绝请求，未必是网络故障；5xx 更可能与服务器或上游服务有关，但需要网站方进一步确认。

单站故障的三种情形

如果只某一个域名解析失败，首先查域名与 DNS；如果浏览器能收到 403/404/503，则站点已经响应，优先检查权限、路径或服务状态；若静态首页正常但登录失败，转查 Cookie 和认证链路。

对比时请用同一个完整网址，包括子域名、路径与 HTTPS 协议，避免把不同网站入口当成同一个结果。

单站点故障不等于整个网络坏了

先区分 HTTP 错误

403 常见于访问限制或权限，404 可能是地址已不存在，5xx 常表示服务端错误；它们与浏览器无法建立连接不同。

核对服务公告

通过网站官方社交账号或状态页面确认是否故障，不依赖随机第三方“在线率”报告。

检查必要资源

网页正文能打开但播放器或登录组件失败，可能是另一个资源域名发生故障。

只有一个网站打不开时别做什么

其他网站正常，说明设备至少具备部分联网能力，但不能证明 DNS、代理或路由对目标站点完全正常。先核对官网地址和服务公告；错误码是 NXDOMAIN、证书警告还是连接超时，会决定下一步方向。

不要为单个域名立刻重置整台路由器，也不要把所有问题归咎于所在地区的网络。

广告

对比测试应控制变量

固定同一设备、同一浏览器，再只更换网络；接着固定网络，只更换浏览器。每次只变化一个条件，才能分清是网站侧、浏览器还是网络路径出现差异。
