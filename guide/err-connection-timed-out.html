ERR_CONNECTION_TIMED_OUT 怎么解决？逐步定位超时原因

Chrome 出现 ERR_CONNECTION_TIMED_OUT 时，先对比站点、网络与设备，再检查代理、DNS 与防火墙。

超时表示什么

ERR_CONNECTION_TIMED_OUT 表示浏览器等待连接相关操作超过了允许时间，但不能单凭这条提示判断网站已宕机。它也不等于服务器明确返回了 HTTP 504，更不等于 DNS 一定出错。

三次对照比反复刷新更有用

  1. 同设备打开另一个可信网站。都超时，检查本机网络、代理和当前接入网络；仅目标站超时，继续往下比较。
  2. 用同一设备切换可信网络。只有某条 Wi-Fi 失败，检查该网络的认证、代理和出口策略；独立网络均失败时查询网站官方状态。
  3. 查看 DNS 是否有结果。Windows 可在终端运行 nslookup example.com，macOS 可运行 dig example.com（换成目标域名）；解析成功仍可能连接超时。
  4. 核对代理或防火墙配置。仅调整自己有权限管理的设置，并保存原值；不要永久关闭安全防护。

不同测试结果如何解释

DNS 能返回地址，但浏览器持续超时：继续查看代理、连接路径或网站状态；DNS 本身失败，则转向 DNS 故障排查。ping 不通不能证明服务器宕机，服务器可能不响应 ICMP。若只有某个页面资源超时，可在浏览器开发者工具的网络面板观察失败请求，而不是认定整站不可访问。

浏览器错误含义也可参考 Google Chrome 官方帮助。
