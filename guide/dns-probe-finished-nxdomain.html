DNS 与证书

DNS_PROBE_FINISHED_NXDOMAIN 怎么办？

解释 NXDOMAIN 的含义，教你检查域名拼写、DNS 缓存和解析记录。

这个错误意味着什么

NXDOMAIN 是 DNS 返回的“查询的域名不存在”状态，不等于网络断开。先检查域名拼写和子域名，例如 login.example.com 与 example.com 不是同一个名称。以下 example.com 仅用作命令格式示例。

用命令验证，别把超时当成 NXDOMAIN

Windows 打开命令提示符，输入 nslookup example.com；macOS 或安装了 dig 的系统运行 dig example.com。只填域名，不填 https:// 或路径。

如何看输出：NXDOMAIN 表示该解析器报告名称不存在；SERVFAIL 表示处理查询失败；timed out 表示没有按时收到解析器响应。这三种结果不能混用。

Windows 的 nslookup 输出措辞可能随版本和语言而变化，看到 “Non-existent domain” 才与 NXDOMAIN 方向吻合；没有这个字样不代表 DNS 一定正常。

交叉比较网络和解析器

  1. 同一网址在手机移动数据与 Wi-Fi 各试一次，排除浏览器输入差异。
  2. 检查系统是否配置自定义 DNS、私有 DNS、代理或家长控制。先记录旧设置，再考虑更改。
  3. 仅本机偶发失败时，再尝试重启浏览器；Windows 可用 ipconfig /flushdns 清理本机 DNS 缓存。此命令不会修复网站的权威 DNS 记录。

不同解析器可能因为缓存和配置给出不同答案；不能仅凭一个公开 DNS 查询就断言网站配置错误。

何时交由网站管理员处理

如果官方正确域名在多个网络持续返回 NXDOMAIN，可能是域名未配置、记录被移除或子域名输入错误。访客无法通过本地改 DNS 创建不存在的权威记录。可以向网站方发送域名、时间和查询返回状态，不要发送私人账号信息。

相关技术概念可查阅 Cloudflare NXDOMAIN 说明。

比较两台解析器时看什么

以下为示意命令，example.com 请替换为实际域名，不能包含 https:// 或斜杠路径：

nslookup example.com
nslookup example.com 1.1.1.1

第二条查询指定的公共解析器，结果不代表“权威答案”，且部分网络可能无法直接访问。若一台解析器返回 NXDOMAIN，另一台返回地址，先记录查询时间与两台解析器，考虑缓存、不同 DNS 视图或网络策略；不要直接判定网站服务器宕机。

如果是公司内网域名，不要随意用公共 DNS 测试结果代替企业解析器的答案。
