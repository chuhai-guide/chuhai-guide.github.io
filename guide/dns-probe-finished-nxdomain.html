DNS 与证书

DNS_PROBE_FINISHED_NXDOMAIN 怎么办？

解释 NXDOMAIN 的含义，教你检查域名拼写、DNS 缓存和解析记录。

NXDOMAIN 到底表示什么

NXDOMAIN 表示所询问的 DNS 解析器回复“这个域名不存在”。它不等于断网，也不等于网站服务器必然关闭。先确认输入的域名拼写、后缀和子域名：login.example.com 与 example.com 是不同的查询名称。

运行一次查询，并读懂结果

Windows、macOS 均可在支持的终端使用 nslookup。将示例域名替换为出错的域名本身，不要填 https:// 或网页路径：

nslookup example.com
nslookup example.com 1.1.1.1

第一行询问系统默认解析器，第二行指定另一个解析器进行对照。NXDOMAIN 是名称不存在的回答；SERVFAIL 是解析器处理失败；timed out 是没有按时收到响应。不同结果不能混为一谈。

结果不同，下一步不同

  • 只有默认解析器失败：检查设备的私有 DNS、企业 DNS、代理和过滤规则，先记录原设置；不同解析器还可能存在缓存差异。
  • Wi-Fi 失败、移动网络正常：优先排查局域网 DNS 和过滤策略；同一个网址在两种网络上对比。
  • 多个可信解析器都返回 NXDOMAIN：再确认是否输入了正确官网域名，必要时联系网站管理员核对域名记录。访客修改本机 DNS 无法创建权威记录。
  • 其实是超时或 SERVFAIL：应转向解析器可达性或处理失败，不能继续按照 NXDOMAIN 处理。

查询时注意隐私

向支持人员反馈域名、时间和查询状态即可；不要发送登录链接中的令牌、私人子域名或内部管理地址。官方技术解释可参考 Cloudflare DNS 基础知识。
