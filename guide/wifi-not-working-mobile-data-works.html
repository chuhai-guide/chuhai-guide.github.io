手机网络正常，Wi-Fi 却打不开网站怎么办

同一网站移动数据可访问、Wi-Fi 不行时，检查路由器、DNS、网络认证和代理。

同一手机切换网络，能说明什么

在同一手机、同一浏览器打开完全相同的网址：Wi-Fi 失败而移动数据成功，说明两条网络路径的表现不同，不能直接认定是网站封锁、DNS 污染或路由器故障。记下具体错误和发生时间。

按照结果缩小范围

  1. 先确认 Wi-Fi 已真正联网。酒店、机场等网络可能需要登录门户；其他网站能打开也不等于目标网站一定可达。
  2. 让第二台设备连接相同 Wi-Fi。都失败，优先核对路由器联网状态、DNS、代理或网络管理策略；只有原设备失败，先查该设备的 Wi-Fi 配置、私人 DNS 和代理。
  3. 检查错误发生在哪一步。明确提示 DNS 解析失败，先查看 DNS 设置；一直等待后超时，继续检查连接路径，而不是仅凭超时修改 DNS。
  4. 保留原有设置。修改 DNS、代理前记录旧值；不要随意将公共或工作网络的设备恢复出厂设置。

家用、公共和单位网络如何处理

家用 Wi-Fi 可以检查路由器 WAN 状态、访问限制和其他设备是否占满带宽；公共 Wi-Fi 要确认认证已完成。办公、学校网络出现策略阻止或代理异常时，向管理员提供域名、时间及两条网络的对照结果，不要擅自绕过管理要求。

如果只是 Wi-Fi 比移动网络慢，而不是完全打不开，应进一步对比信号强度、拥塞和其他设备占用。
