手机网络正常，Wi-Fi 却打不开网站怎么办

同一网站移动数据可访问、Wi-Fi 不行时，检查路由器、DNS、网络认证和代理。

先确认：不同错误提示对应的排查方向不同。请保留浏览器显示的完整错误代码，避免同时修改多项设置。

这个对比说明什么

换了接入网络后恢复访问，说明故障与原 Wi-Fi 相关的可能性增加，但仍不能直接确定是 DNS 还是链路。

优先检查四处

  1. 确定 Wi-Fi 是否完成认证

    酒店、机场和部分公共网络需登录门户。浏览器可能误以为已经联网。

  2. 用其它设备连接相同 Wi-Fi

    只有一台设备失败，重点看设备代理、私人 DNS 或配置；所有设备失败，重点看路由器和上游网络。

  3. 核对 DNS 与代理设置

    确认没有过期的代理地址或错误手动 DNS。改动前记录旧设置。

  4. 重启路由器并查看状态

    若你有管理权限，可重启并查看 WAN 状态；办公或公共网络应联系管理员，不要擅自重置设备。

如何判断下一步

若移动网络一直正常而 Wi-Fi 只对特定海外域名失败，可记录域名、时间、错误代码和对比结果，向网络提供方咨询。

按网络层级定位

同一手机移动数据可访问而 Wi-Fi 不行，说明网站并非必然整体宕机。请再让另一台设备使用同一 Wi-Fi：若也失败，关注路由器 DNS、代理、公共 Wi-Fi 登录和网络策略。

如果只有一台设备在 Wi-Fi 下失败，优先检查其私有 DNS、VPN/代理、浏览器配置及是否意外保存了错误网络设置。路由器恢复出厂设置应放在最后，并提前备份配置。

同一手机做对照最有价值

先避免设备差异

用同一手机分别连接 Wi-Fi 与移动数据，打开完全一致的网址并记录报错。

家用 Wi-Fi

确认是否需要路由器重连、DNS 设置是否被更改、是否启用代理或家长控制；修改前拍照记录原配置。

公司或学校 Wi-Fi

可能存在身份认证、允许名单或安全策略，优先联系管理员而非绕过限制。

排查完如何判断

移动网络稳定且 Wi-Fi 多设备异常，更可能涉及该 Wi-Fi 或上游出口；只有一台设备异常则优先检查其 Wi-Fi 网络配置。

用同一设备做有意义的 Wi-Fi 对照

保持手机、浏览器和网址不变，先用 Wi-Fi 打开，再关闭 Wi-Fi 用移动数据重试。若仅 Wi-Fi 失败，先排查是否需要网页认证、路由器 DNS、系统代理或网络过滤；若只是 Wi-Fi 慢，继续检查信号、拥塞和其他设备占用。

记录修改前的 DNS 或代理设置。单位、学校网络应优先咨询管理员，不要自行绕过管理要求。

广告

避免误判为网站封锁

同一手机使用移动数据可以访问、Wi-Fi 无法访问，仅能证明两种网络环境存在差异。先检查路由器联网状态、DNS、代理或公共 Wi-Fi 登录门户；办公网络则先咨询管理员。
